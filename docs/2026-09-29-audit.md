# Caddo Trading Company — original-site audit and redesign

**Source and verification date:** September 29, 2026.
**Starting repository revision:** `a9e8106009c1c12a17d0ed13c07b80491941c027` (August 26).
**Status:** redesigned and checked locally; prepared on a review branch. The original domain is unchanged.

## What the investigation established

The original site is much more intact than its appearance suggests. Its core catalogs, certification page, ordering instructions, museum information, and several related pages still respond. Its photographs and descriptions are worth keeping, but a successful page response is not evidence that an item is still for sale.

The audit checked **45 primary URLs**: 41 returned HTTP 200, three returned 404, and the HTTPS homepage failed certificate validation. Three additional known broken links also returned 404. Discovery followed the homepage and inventory index, then one further level of same-domain HTML links. This is a bounded audit, not a claim that every possible legacy URL or external link was discovered.

**eBay is the working online sales channel.** The [Caddoman store](https://www.ebay.com/str/Caddoman/) loaded in the browser and displayed 80 items, 100% positive feedback, approximately 3.5K items sold, and 749 followers at the time of inspection. Those changing numbers are recorded here, not hard-coded into the marketing page.

The [original ordering page](http://www.caddotc.com/Catalogue/Catalogue.htm) tells customers to contact Sam, pay by check or money order, or call about Visa/MasterCard. It has an obsolete eBay link and a malformed email link. **No shopping cart, checkout form, or separate payment portal was found in the 45 inspected pages.** This does not rule out an unlinked private payment process. No transaction was attempted. Direct payment methods must be confirmed with Sam before being promoted as current.

## Original-site problems found

- The homepage’s museum text links to a developer’s old `file:///C:/...` path. Visitors cannot use it.
- The “New Catalogue Items” navigation contains both a working `/NewItems/NewItems.htm` link and a broken `/Catalogue/NewItems/NewItems.htm` target.
- `/Home.html` and `/Catalogue/Inventory/KaDoHaInfo/kadoha.html` return 404. The correct museum paths above still work. The August audit’s broad inference that museum information was missing was therefore incomplete.
- A link on the ordering page resolves to `/Catalogue/caddotc@windstream.net` and returns 404 instead of opening email.
- The layout uses fixed-width tables, image navigation, hover/click handlers, tiny text, old scripts, and long repeated keyword paragraphs.
- Different museum pages list different admission prices. Old excavation notices refer to events in 2002–2005. These remain historical records, not reliable current offers.
- Certification still lists $20 and $25 service prices, but the age of the page makes current confirmation necessary.
- The ordering page has a mailing ZIP discrepancy compared with the homepage. The redesign does not give unverified mailing-payment instructions.
- HTTP availability is not secure HTTPS availability. The original certificate fails hostname validation; the GitHub Pages prototype itself uses HTTPS.

## Preservation completed

The local preservation archive contains raw HTML responses and source URLs, a manifest of image URLs and SHA-256 digests, and downloaded original image bytes.

- **3,067 same-domain image references checked.** Two external image references were excluded from this preservation pass.
- **3,056 image files preserved**, representing 3,043 distinct file hashes and **70,078,894 bytes** (about 70 MB).
- **11 image URLs returned 404.** The one initial network timeout succeeded on retry.
- **Zero saved-file hash mismatches.** Strict decoding found one already-truncated source JPEG, `KaDoHaInfo/Digs/2005Dig-051.jpg`; the original bytes were preserved, and it is not used in the redesign.
- Image references include decorative graphics, thumbnails, and repeated files; these counts are **not artifact or inventory counts**. The old “5,000+ pieces” estimate was not substantiated.
- The original repository’s 50 image assets are retained. The new trading-post photograph comes from `/KaDoHaInfo/Store/store4-sm.jpg` and is labeled as an original-site photograph.

The large preservation archive stays local and is not uploaded with the marketing site. HTML snapshots preserve the original text and markup, but the archive is not advertised as a fully rewritten offline website. It retains source maps so missing material can be traced later.

## New visitor experience

1. **Shop:** persistent header link and primary homepage action take visitors to Caddoman on eBay. No stale product prices or “available now” claims are maintained locally.
2. **Explore:** a searchable directory links all 19 original inventory categories plus the original arrivals page, with arrowheads page 2 also retained. It explains the distinction between historical listings and current inventory.
3. **Certification:** the real certificate sample and direct contact options remain. Visitors are asked to confirm fees, submission details and timing.
4. **Visit:** real place information, the original trading-post image, directions and appointment guidance replace media placeholders.
5. **Contact:** Sam’s original portrait, telephone and email remain prominent. There is no form that silently drops a message.

The layout uses warm paper tones, dark ink, restrained gold accents, generous spacing, readable serif headings, and a naturally proportioned original logo. Images retain their source appearance and are contained rather than aggressively cropping artifacts. It has no external font dependency, framework runtime, analytics, third-party embed, or inventory API requirement.

## Verification and limits

- Homepage and archive render in the browser with real content and functioning navigation.
- Visually inspected desktop and phone layouts, including 390px and 320px viewport overrides. No horizontal overflow was found at those phone sizes; overrides were reset afterward.
- Archive search for “Pottery” shows one category. An unmatched search shows zero and a Clear search action. Clearing restores all 20 categories and returns focus to the search field.
- A real eBay CTA was clicked and reached the Caddoman store.
- Mobile menu opens, links navigate, and the menu closes after a selection. FAQ expansion exposes the correct answer.
- No broken loaded images or first-party browser errors were observed. eBay emitted its own tracking-header warnings during the external navigation; those are not errors from this site.
- Local check: 11 HTML pages and 73 local references pass, with no missing files, missing fragments, duplicate IDs, missing image dimensions/alt attributes, or invalid sitemap XML. JavaScript syntax and Git whitespace checks pass.
- Tested interactions stop before email sending, phone calling, transactions, or changing the original domain.
- Original catalog links still depend on the old server, and those pages remain visually old. Their content has been backed up so a later complete catalog migration is possible.
- This is browser and static validation, not a formal accessibility certification or a claim of testing every physical device.
